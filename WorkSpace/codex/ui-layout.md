# 桌面工作台布局

用户目标：取消“目录 / 工作簿工作表 / 日志”三层上下堆叠；日志选用独立页面。

主任务路径：左侧选择工作簿和工作表 → 右侧编辑规则 → 顶部执行转换或同步 → 状态栏反馈，需要时查看日志。

- 左侧为固定导航，默认宽 270，可拖动至 230–360。文件名和表名保持单行，长名称用提示展示完整内容。
- 右侧单一大工作区：规则编辑、目录与同步、运行日志。规则编辑内部继续保留基本设置、字段映射、子表规则、其他配置。
- 目录作为独立滚动表单，标签与路径上下排列；不再限制在 190 高度的嵌套滚动框内。
- 日志页使用剩余全部空间，底部只保留 36 高的状态栏和日志入口。失败可跳转日志，普通进度不抢页面。
- 运行时锁定导航中的编辑操作、规则输入、目录输入；工作区页面切换及日志查看始终可用。
- 默认窗口 1280×820，最小 1000×680；页面内部滚动，避免整体挤压。顶部动作和底部状态位置稳定。

沿用 WPF 原生控件和现有克制配色：正文 #1F2937，辅助文字 #596579，强调 #2563EB，主表面白色，侧栏 #F1F4F8，边界 #DCE1E8。正文 13，主区域标题20，应用标题22；间距以4为基准，区域内8/12，组间24/28。无需新增图像或外部字体。

验证：WPF 自动检查保存、转换、行数刷新、规则开关和重新打开；额外检查运行中日志可用与已选规则可见、状态栏不越界、左侧列表有效高度。真实已保存规则分别渲染 1240×780、1000×640 客户区的三个页面，截图位于 codex/UiSmokeTests/bin/Debug/net8.0-windows/fixtures/layout-*.png。Impeccable detector 返回空列表，其对 XAML 的覆盖有限，以实际渲染和行为检查为准。
